Comece por aqui

  1. Abra Criativos e escolha um número no Mapa dos vídeos. Ali estão a fala e as orientações para produzir cada peça.
  2. Use Falas para gravação para consultar só o que será falado. Os dois arquivos apresentam os mesmos vídeos, sem duplicar gravações.
  3. Em Estáticos, confira os textos e as referências de montagem. As prévias mostram a composição, sem substituir as imagens de produção.
  4. O Tutorial do domínio reúne os passos para alinhar o endereço desta página e preservar os serviços existentes.

Os documentos abrem neste navegador. Se preferir uma cópia local, baixe o HTML e abra no computador.
